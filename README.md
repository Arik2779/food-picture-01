# Best-looking food picture — double smash cheeseburger

Entry for make.fun `food-picture-01`: a program (`main.ts`, Node 22,
standard library only) that writes one photograph to `/output/entry.png`.

The picture is a double smash cheeseburger — glossy sesame brioche bun,
two charred patties, melted cheddar dripping down the sides, lettuce and
tomato, crispy fries on a dark slate board in warm golden light. The image
was generated for this entry (1024×1024 JPEG, 181,478 bytes).

Run it:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

It copies `entry.png` to the output directory and checks the copy is whole.
Two runs write identical bytes.
